# Research anime using Annict and Pixiv Encyclopedia

## Consult both discovery sources

- Consult both [Annict](https://annict.com/works) and [Pixiv Encyclopedia](https://dic.pixiv.net/) for each request, whether the starting point is a work, character, episode, or scene. Start with whichever can resolve the query more directly. If either source has no relevant page or cannot be accessed, continue with the available sources.
- In Annict, search by title or browse by release season to find the work, cast, episode list, and official links. If needed, try `site:annict.com/works "作品名" 放送年`.
- In Pixiv Encyclopedia, search for the work, character, or distinctive scene term with `site:dic.pixiv.net/a`. Open relevant articles for context such as alternate names, relationships, story terminology, and episode clues. Check which adaptation they cover and follow their citations when available. If an article is inaccessible, use the search results to identify leads and verify them elsewhere.
- If the title is unknown, use article leads and searches such as `"キャラクター名" アニメ` to identify candidates, then check the relevant Annict and official pages. If multiple plausible matches remain and the choice changes the answer, ask which one the user means.

## Confirm the work and version

- Match the title, season, and format on the Annict work page. Distinguish seasons, films, specials, and source games. Use Cast (キャスト) for roles and voice actors and Episodes (エピソード) for episode numbers, titles, and individual pages.
- Open the official site linked from Annict. If the link is missing or broken, search by title, format, release year, and `公式`.
- For *CUE!*, use the [verified links and search examples](references/cue.md).

## Verify character and cast information

- Open official pages and check the title, version, and publisher. Use CHARACTER for profiles and name readings, and STAFF / CAST for role and actor credits. If text extraction omits the content, try the rendered page. Check an official announcement or a production studio's work page for any missing fields.
- Use `site:official-domain "キャラクター名"` to find directly relevant pages. If a publisher's announcement also covers a source game or live event, use the section explicitly about the anime adaptation.

## Search for episode content and scenes

- For a known episode, match its number and title in Annict. Open the official STORY or EPISODE page, the broadcaster's episode guide, or a licensed streaming service's episode listing. Search with `"作品名" "第N話" "話タイトル"` or `site:official-domain "話タイトル"` when navigation is unclear.
- When the episode is unknown, search the title with a character, setting, or distinctive action and terms such as `何話`, `場面`, or `あらすじ`. Use Annict's episode list to check candidate numbers and titles. Search snippets, user posts, and wikis can suggest candidates. On pages that show several episodes, check which episode heading the matching description belongs to.
- For exact scene details, use the episode itself or an official clip when accessible. Cite the episode or clip and add a timestamp only if verified. Where only an official synopsis or licensed platform listing is available, report the details it supports. If the available sources leave the episode or detail uncertain, say so.

## Answer in Japanese

- Identify the work and version. Link to the relevant Annict work or episode and cite the specific page or video that supports each requested fact. Attribute official evidence to its publisher. If a detail is available only from Pixiv Encyclopedia or another secondary source, link to the individual article and say that official sources did not verify it. Omit fan interpretations unless requested.
- Summarize only the events needed for the answer in your own words. Avoid spoilers beyond the requested scope. Link to source material and omit verbatim synopses, character profiles, dialogue, setting documents, and images from both the skill and its answers.
